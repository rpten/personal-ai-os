# Instruções para agentes (Codex / ChatGPT)

Este repositório é a fábrica de projetos de Rafael. O protocolo completo está em `CLAUDE.md` e vale para qualquer agente.

Ao atuar aqui (ex.: revisão pelo ChatGPT via conector do GitHub, ou execução pelo Codex):
- Leia `CLAUDE.md` e o `projects/<slug>/state.json` do projeto em questão.
- Não altere o estado de um projeto em `executing` sem coordenar pela issue.
- Revisões e sugestões entram como comentário no PR ou na issue, para ficarem no mesmo histórico.
